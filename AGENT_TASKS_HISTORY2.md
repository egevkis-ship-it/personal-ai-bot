## HIST2-1 — группировка списка по месяцам/неделям (основное)
`History()` сейчас — плоский список карточек по дате. Сгруппировать завершённые:
- Месяц — sticky-заголовок «Июнь 2026» + сводка справа (число тренировок + суммарный
  тоннаж за месяц);
- внутри месяца — тонкие под-разделители по неделям (Пн–Вс в tz юзера): «23–29 июня»
  + число тренировок недели;
- карточки — как сейчас (день недели · дата · подходы · тоннаж), date-desc, новейший
  месяц сверху;
- при активном поиске — плоский отфильтрованный список без секций;
- «📄 Отчёты (PDF)» и «➕ Добавить тренировку» в шапке остаются.
Фронт-онли: группировать `/api/workouts` на клиенте; суммы из `tonnage`/`set_count`.
