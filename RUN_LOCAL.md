# Запуск прототипа на компьютере

Прототип = **FastAPI-бэкенд поверх кода бота** + **PWA-фронтенд**. Работает с настоящей
базой (Postgres) и не требует ключей AI. Бот при этом не трогается.

## Вариант 1 — Docker (рекомендую)

Нужен установленный **Docker Desktop**.

```bash
cd personal-ai-bot
docker compose -f docker-compose.app.yml up --build
```

Открой в браузере на компьютере: **http://localhost:8000**

При первом запуске база сама заполнится демо-данными (план на сегодня, пара прошлых
тренировок, замеры) — чтобы было что потыкать. Останов: `Ctrl+C`, удалить данные:
`docker compose -f docker-compose.app.yml down -v`.

## Вариант 2 — Без Docker (если есть локальный Postgres)

```bash
cd personal-ai-bot
python3 -m venv .venv-api && source .venv-api/bin/activate
pip install -r requirements.txt fastapi "uvicorn[standard]"

export DATABASE_URL="postgresql+asyncpg://postgres:postgres@localhost:5432/fitness"
export REDIS_URL="redis://unused/0"
export TELEGRAM_BOT_TOKEN=local ANTHROPIC_API_KEY=local OPENAI_API_KEY=local APP_USER_ID=local

uvicorn api.main:app --reload --port 8000
```

Открой **http://localhost:8000**.

## Открыть на iPhone (без App Store)

1. Телефон и компьютер — в одной Wi-Fi сети.
2. Узнай локальный IP компьютера (macOS: Системные настройки → Wi-Fi → Подробнее, вида `192.168.x.x`).
3. На айфоне в Safari открой `http://192.168.x.x:8000`.
4. Кнопка «Поделиться» → **«На экран Домой»** — появится иконка, запускается как приложение.

> Заметка: на телефоне `localhost` — это сам телефон, поэтому нужен именно IP компьютера.
> Если не открывается — на компьютере разреши входящие подключения для Docker/питона в фаерволе.

## Что уже работает в прототипе

Тренировка целиком: старт (по плану / другой день / повтор / свободная), чеклист плана,
карточка упражнения, ввод подхода (стрелки + тап по числу + текст/«до отказа»), типы
упражнений (вес×повторы / время с таймером / вес тела), таймер отдыха, правка/удаление
подходов, добавление упражнений (недавние / по группам / поиск), пауза и возобновление,
заметка, завершение с резюме. Плюс замеры (9 полей + ввод текстом + история с графиком)
и история тренировок.

Пока не в прототипе (есть в дизайне): фото-прогресс, PDF-отчёты, ИИ-генерация планов и
ИИ-резюме (резюме сейчас считается без ИИ — тоннаж и динамика).

## Частые проблемы

- **Порт 8000 занят** — поменяй `8000:8000` в `docker-compose.app.yml` на `8080:8000`, открывай `:8080`.
- **Конфликт Postgres** — наружу проброшен `5433`, чтобы не мешать локальной базе; внутри сети всё на 5432.
- **Пустые экраны** — дёрни сидер заново: `curl -X POST http://localhost:8000/api/dev/seed`.
