## EXP-1 — Текстовый экспорт тренировки (одна + период)
Сейчас экспорт только машинный: `/api/export?format=csv|json` (плоско) и PDF (`/api/reports`).
Нужен ЧЕЛОВЕКОЧИТАЕМЫЙ текст — чтобы скопировать/поделиться и чтобы его же можно было вставить
обратно через текст-импорт (HIST-2, `parse_logged_workouts_text`).
- **Формат** (зеркало того, что понимает импорт-парсер — сверься с `parse_logged_workouts_text`):
  ```
  2026-07-04 · Плечи приоритет + руки
  📝 общая заметка тренировки (если есть)
  Жим гантелей сидя: 20×12, 22×10, 22×10
    📝 болело плечо, снизил вес
  Махи гантелями в стороны: 10×15, 12×12
  Махи в кроссовере: 15×15, 15×12
    📝 хороший памп

  2026-07-02 · Ноги
  ...
  ```
  - заголовок — дата ISO `·` фокус; упражнение — `Название: подходы через запятую`;
  - силовое → `вес×повторы`; bodyweight → просто повторы; кардио/планка → `мм:сс`;
    разминка → пометка `(р)`, до отказа → `*` (как в PDF/`setLabel`);
  - несколько тренировок — разделены пустой строкой; порядок дат — как удобнее импорту
    (проверь, что парсер съедает свой же вывод — round-trip).
- **Комментарии обязательно.** Источник — `assemble_workout` (уже подмешивает `ex.notes` из
  `workout_exercise_notes`, W3-4): под упражнением строкой `  📝 <текст>`; заметка всей
  тренировки (`workouts.notes`) — под заголовком. Ничего не терять. НЕ изобретать новый SQL —
  брать готовую сборку из `assemble_workout`.
- **Эндпоинты** (owner-scoped):
  - `GET /api/workouts/{wid}/text` → `{ "text": "..." }` — одна тренировка;
  - `GET /api/export?format=text&from=&to=` → текст за период (расширить существующий
    `/api/export` новым `format=text`; media_type `text/plain; charset=utf-8`).
- **Фронт:**
  - в детали тренировки (История → карточка; активная/архивная) — кнопка «📋 Скопировать
    текстом»: тянет `/text`, кладёт в буфер (`navigator.clipboard.writeText`, фолбэк — показать
    textarea для ручного копирования), тост «Скопировано»;
  - в шапке Истории рядом с «📄 Отчёты (PDF)» — «📝 Текст» за тот же период (тот же
    диапазон-пикер, что у PDF-отчёта).
- Acceptance: у любой тренировки можно получить читаемый текст с подходами И комментариями;
  период экспортируется текстом; вставка этого текста обратно в HIST-2 импорт-превью распознаёт
  те же тренировки (round-trip; комментарии в экспорте присутствуют).
